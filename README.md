# 臺北市 市政Debug松｜六題總覽：頁面素材

這個 repo 放 yojuhsu.com/2026-taipei-debug 那一頁用到的資料、影片和圖。頁面本身在 yojuhsu.com，這裡的檔案由頁面直接讀取。

## 檔案

- `data/six.json`：456 個里的邊界、人口和六題的欄位，以及垃圾桶那一題的 3,460 個公車站牌。數字取自六題的頁面。
- `data/time.json`：地圖上的時刻資料。公車那一題每個里 24 個鐘點的分組、鼠患那一題的垃圾車停靠點與時間、公車那一題記下的公車實際位置。
- `data/q4.json`：內湖塞車那一題的頁面網址。
- `data/recap.html`：回顧文章的內文，跟部落格上的文章同一份。
- `media/q1.mp4` 到 `media/q6.mp4`，以及 `q*_poster.jpg`：六題的短片和封面。畫面由程式逐格畫出，片中人物是 AI 繪製。
- `media/q*_info.*`：各題頁面上的資訊圖。
- `chars/`：頁面上的人物和機器人。

## 圖與影片

- 人物和機器人都是 AI 繪製（OpenAI 圖像生成）的虛構角色，不是任何真實人物的肖像。
- 資料的原始出處與年份，寫在各題的頁面上。
